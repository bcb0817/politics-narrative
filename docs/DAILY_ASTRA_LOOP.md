# 本番再開と日次改善ループ（2026-09-08）

ユーザーの明示指示により、Astra版の主WindowsタスクPoliticsNarrativeBotを再開する。
停止を指示された過去の記録に優先する。旧Threads・動画・災害・note・20件目標の各投稿タスクは停止を維持。
本文生成はgpt-6-astra、日8件以下・90分以上間隔、既存予算と安全ゲートは維持する。

既存Codex自動化bot-20を「時事ネタBot 日次ログレビュー・自動改善」へ更新しACTIVEにした。
毎日05:10 JST（初回予定2026-09-09）。コード改善担当は既存設定のgpt-5.6-terra/mediumを維持し、
投稿本文のAstra指定とは分ける。重複した自動化は作成しない。

ループ: 前日ログ/DBレビュー → 根拠付き課題1〜2件 → 小さく可逆的な実装 →
隔離テスト → 主Bot停止/反映/再起動 → 実態確認 → commit/push/draft PR更新 → 日本語報告。
根拠不足・正常な品質保留・外部API障害のみなら不要な変更をしない。
既存の未コミット変更・秘密情報を保護し、変更前はcreate_backup.ps1を実行する。
品質/予算/重複防止/ambiguousを緩和せず、テスト投稿・強制投稿・削除済み旧生成物の復活を禁止。
実測インプレッションを観測条件と欠測率付きで比較し、旧モデル実績は編集改善に混ぜない。
ユーザーが後で停止した場合は自動再開しない。

ローカル自動化のため、実行ホスト・Codexの実行環境が利用可能であることが前提。
毎日の成功を保証する仕組みではなく、失敗・権限不足はその回の結果で報告する。

起動確認で判明した既存不具合: local_bot.logのファイル追記がatomic_write_text内へ
誤配置され、未定義lineの例外が握りつぶされていた。ログ追記を独立関数に戻し、回帰テストを追加。
これによりdaemon起動/次回実行の記録を日次ループが参照できる。
