# ChatGPT日次レビュー運用ガイド 📊

## 処理

毎日04:40 JSTに、直近24時間のBot投稿と取得済みX指標を集計します。

1. インプレッション、表示速度、反応率、保存、引用、プロフィール遷移を集計
2. 投稿型、フック、時間帯、文字数、文章構造別に比較
3. 投稿失敗・スキップ理由を件数だけ集計
4. OpenAI Responses APIへ構造化データを1回送信
5. ChatGPTが根拠Tweet ID、指標、信頼度付きの翌日方針を返す
6. Botが許可済み項目だけを検証し、最大48時間の方針として有効化
7. 投稿候補を決定論的に施策群80%・対照群20%へ割り当てる
8. 施策群だけに方針を反映し、対照群は従来ロジックを維持する
9. 両群3件以上の表示速度を比較し、明確な悪化時は方針を自動停止する
10. Threads専用生成にも同じ割り当てと検証済み方針を反映する
11. Discordには生ログではなく、更新・継続・停止の結果だけを通知する

## 自動反映できる項目

- 通常投稿型の優先順位
- フック型の優先順位
- 推奨時間帯
- 100〜260字の範囲内の目標文字数
- 許可済み文章構造
- 許可済み締め方

## 自動変更できない項目

- 事実確認基準と一次資料要件
- BAN・個人攻撃・扇動・名誉毀損の安全基準
- 政治的立場、政党・候補者への評価
- 投稿間隔、日次上限、重大速報上限
- OpenAI、X、xAIの予算
- APIキー、Webhook、プロフィール、外部公開設定

## 有効化条件

- 直近24時間に3件以上の計測対象がある
- OpenAI分析が正常終了している
- 少なくとも1件の提案に、実在するTweet IDと計測指標がある
- 信頼度が0.55以上
- 値がBotの許可リストと上限内に収まる

条件を満たさない日は従来のローカル集計だけを使用し、投稿処理は停止しません。

## 効果測定とロールバック

- 同じ方針IDと実験名をX投稿履歴へ記録
- 投稿ごとの割り当てはtopicと方針IDから決定し、再実行しても変えない
- 方針の文章構造、フック、投稿型、推奨時間への一致は最大0.25点だけ加点
- BAN、未確認情報、重複、投稿上限、予算のゲートは加点より先に判定
- 施策群または対照群が3件未満なら、方針を入れ替えずデータ収集を継続
- 施策群の表示速度が対照群の80%未満なら自動停止
- 訂正、手動削除、安全性低下を施策群で検知した場合はサンプル数に関係なく自動停止
- 有効化、評価、停止は`data/chatgpt_strategy_history.jsonl`へ監査履歴として保存

## 状態確認

```powershell
.\.venv\Scripts\python.exe local_bot.py review-strategy-status
```

状態表示には直近10件の有効化・評価・停止履歴も含まれます。

手動停止は確認フラグ付きで実行します。

```powershell
.\.venv\Scripts\python.exe local_bot.py review-strategy-disable --confirm
```

停止するときは`.env`で次を設定します。

```dotenv
CHATGPT_DAILY_STRATEGY_ENABLED=false
```

## 調整可能な環境変数

```dotenv
CHATGPT_DAILY_STRATEGY_TREATMENT_RATIO=0.80
CHATGPT_STRATEGY_EVAL_MIN_PER_ARM=3
CHATGPT_STRATEGY_ROLLBACK_RATIO=0.80
```

施策群比率は50〜90%、評価最低件数は各群2〜20件、ロールバック比率は
0.50〜0.95の安全範囲へ自動補正されます。
