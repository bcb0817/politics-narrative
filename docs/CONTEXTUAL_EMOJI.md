# 絵文字の編集方針（2026-09-08）

冒頭の「📌」を定型で付けるスタイルを廃止。旧処理の自動付加と絵文字必須判定を削除した。
本番Astraの生成・検査指示に、絵文字は任意、話題を分かりやすくする場合のみ自然に最大1個、
深刻な話題では使わないことを明示。絵文字なしを減点しない。
冒頭📌は検査で拒否するが、内容に対応した絵文字全般を禁止するものではない。
旧.envのEMOJI_REQUIRED=trueは本番本文の必須条件にしない。

config/topical_editor.jsonのemoji_styleを候補キャッシュキーに含め、
旧スタイルの保存候補を新しい設定で再利用しない。送信履歴・費用台帳は保持。
投稿数、予算、事実性、品質、重複防止は変更しない。公開済み投稿の編集・削除は行わない。

既存の未コミット版にある_repair_candidate_formatにも同じ修正を適用。
その差分はproduction/contextual_emoji_draft.patchに保存し、未コミット開発全体はコミットしない。
検証: tests.test_contextual_emoji と既存投稿経路の回帰テスト。検証中の外部投稿なし。
