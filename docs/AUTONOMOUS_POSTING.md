# 自律投稿モード 🤖

`AUTONOMOUS_POSTING_ENABLED=true` のとき、外部投稿は人間の承認待ちを
挟まず、各投稿ジョブが自動で実行します。

## 対象

- Xの通常投稿・長文リサーチ分析投稿
- Threadsの通常投稿
- 検証済み災害更新と訂正投稿
- 有効化済みのX・Threads動画投稿
- Threadsの個別アクション（アクション固有スイッチが有効な場合）

## 維持する安全ゲート

人間承認を廃止しても、次の機械判定は無効化しません。

- 公式情報・一次資料の確認
- 品質スコアと投稿価値
- BAN・名誉毀損・個人攻撃リスク
- 同一テーマ・同一主張・URLの重複防止
- 投稿間隔と日次上限
- OpenAI・xAI・X APIの予算上限
- APIクォータと緊急停止
- タイムアウト時のブラインド再投稿禁止

## 非対象

投稿ではない削除、データ削除、アカウント設定変更、Windowsタスクの
登録・削除は自律投稿モードだけでは実行しません。これらは誤操作時の
影響が投稿より大きいため、個別の実行指示を必要とします。

noteには公開用の公式APIがないため、ドラフト生成・画像生成・Discord通知
までは自動ですが、noteサイト上の公開操作はこのモードの対象外です。
