# 炎上ハンター：承認済み予算と有効化条件

2026-10-09承認：専用日次3 USD、月次60 USD。1実行1 USD。
既存BotのX・xAI・総API予算は変更せず、共有台帳の上限も適用する。
未確定費用・超過時は次の呼び出しを止め、予約や履歴をリセットしない。

検索には `max_turns: 2` を送る。これはラウンド数であり、個別検索数や
課金のハードキャップではない。`max_tool_calls` だけで抑制できるとは扱わない。
タイムアウトは360秒。応答不明時の自動再送は禁止。
X Searchの日付終端はUTCの排他的上限なので、日中の終了時刻には翌日を渡す。
取得窓は日付単位で広がるため、厳密な24時間ランキングには投稿日時の検証が必要。

公式仕様：
- https://docs.x.ai/developers/tools/x-search
- https://docs.x.ai/developers/tools/tool-usage-details
